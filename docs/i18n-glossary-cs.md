# Czech glossary (binding for all Czech text)

Tone: fantasy card game, natural modern Czech, short UI labels, rules text precise and consistent.
Use second person informal ("tvůj", "zahraj") in rules and UI. Numbers stay digits. Keep "I / II / III" ranks.
Use typographic quotes „…“ and the ellipsis "…" where English uses them. No trailing spaces.

Rules-text patterns (follow these):
- "On Deploy: Deal 2 damage." → "Při nasazení: Způsob 2 poškození."
- "Last Breath: Summon a 1/1 Hollow Wisp." → "Poslední dech: Vyvolej Prázdnou světlušku 1/1."
- "Whenever …" → "Kdykoli …"; "At the start of your turn, …" → "Na začátku tvého tahu …"; "At the end of your turn, …" → "Na konci tvého tahu …"
- "this turn" → "v tomto tahu"; "Once per turn." → "Jednou za tah."; "Twice per turn." → "Dvakrát za tah."
- "a random enemy" → "náhodnému nepříteli"; "a friendly unit" → "spřátelené jednotce"; "all enemies" → "všem nepřátelům"; "the enemy Warden" → "nepřátelskému Strážci"; "your Warden" → "tvému Strážci"
